## Task 3
Dashboard Creation Using Power BI

## Objective
The objective of this task is to create a sales dashboard using Power BI to present important sales metrics and business insights in a clear and easy-to-understand format.

## Tools Used
- Power BI
- Microsoft Excel
- Python
- Pandas

## Dashboard KPIs
- Total Sales
- Total Orders
- Average Order Value

## Visualizations
- Sales by Category
- Sales by Region
- Sales by Product
- Sales Details Table

## Key Insights
- Electronics generated the highest category-wise sales.
- Laptop was the top-performing product.
- North recorded the highest regional sales.
- The dashboard provides a clear overview of sales performance.
